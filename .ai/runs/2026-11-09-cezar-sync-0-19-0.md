# Execution plan — sync the PWA to Cezar v0.19.0 (7225a3d)

Issue: #131

## Goal

Pin the vendored contract to Cezar 0.19.0 (npm `gitHead` / tag `v0.19.0` = `7225a3db990d7fc2a09525b6148e8e9001a8c1e2`), bump `TESTED_CEZAR_VERSION` to `0.19.0`, port the `attention.ts` delta (idle-closed, switching agent, the `idle` tone), extend the runner list, and record the 0.18.0 → 0.19.0 delta in `docs/CEZAR_API.md`.

## Scope

- `packages/cezar-contract/` via `npm run sync:contract 7225a3db990d7fc2a09525b6148e8e9001a8c1e2` (no hand edits).
- `apps/pwa/src/config/cezar-compat.ts`, tests naming the tested version, health fixtures (`runtimeId`).
- `packages/shared/src/attention.ts` (+ tests), the PWA status dot tone mapping, `src/i18n/en.ts`, the sidecar's failure-push decision.
- `apps/pwa/src/domain/new-task.ts` `RUNNERS`.
- Confirm `history-truncated` never reaches the PWA (it always resumes with `afterSeq`) and is ignored if it does.
- `docs/CEZAR_API.md`.

## Non-goals

- Fallback-policy settings, live usage gauges, Run First (`/promote`), reasoning effort, HTML artifacts / Assess Impact, automations export/import, the config bundle, agent onboarding.
- The host upgrade (handled outside this run). No Cezar restart. No merge.

## Implementation Plan

### Phase 1: Contract sync

1. Run the sync script at the 0.19.0 sha; confirm the vendored diff is limited to what upstream changed.
2. Bump `TESTED_CEZAR_VERSION`, the tests that name it, and add `runtimeId` to health fixtures.

### Phase 2: Port upstream changes

1. Port `isIdleClosed`, the `closed · idle` rung, the `switching agent` rung and the `idle` tone into `packages/shared/src/attention.ts` with table-driven tests.
2. Map the `idle` tone in the PWA status dot and add the new labels to `en.ts`; check the sidecar no longer pushes a failure for an idle-closed run.
3. Extend `RUNNERS` with `omp`, `antigravity`, `gemini`, `kimi`.
4. Confirm the `history-truncated` frame cannot break the run-events stream.

### Phase 3: Docs

1. Add the 0.18.0 → 0.19.0 delta to `docs/CEZAR_API.md`.

## Risks

- A tone the PWA does not map would render an unstyled dot; prevented at compile time: `TONE_CLASS` is a `Record<AttentionTone, string>`, so a tone without a class fails `npm run typecheck`.
